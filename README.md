# 🌸 Iris Flower Classification

Classifying iris flower species using Machine Learning in Python.

---

📌 **Summary**
- **Problem:** Accurately identify iris flower species (Setosa, Versicolor, Virginica) based on physical sepal and petal measurements.
- **Dataset:** Classic Iris dataset loaded directly from `scikit-learn`, cleaned, and analyzed.
- **Key Insight:** Exploratory Data Analysis and visualization revealed that **petal length and petal width** are the most discriminative features for species separation.

---

🛠️ **Tech Stack**
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Scikit-Learn

---

📊 **Models & Performance**
1. **Logistic Regression** (Linear Classifier)
2. **K-Nearest Neighbors (KNN)** (Distance-based Classifier)

| Model | Accuracy | F1-Score |
| :--- | :--- | :--- |
| **Logistic Regression** | ~97.8% - 100% | ~1.0000 |
| **K-Nearest Neighbors** | ~95.5% - 100% | High |
